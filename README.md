# Luma — Landing Page

A modern, responsive landing page designed for **Luma**, a fictional productivity platform that helps users organize their day, stay focused, and track progress.

This project was created as a frontend development project to practice responsive layouts, smooth navigation, animations, and interactive UI elements.

## ✨ Features

* Responsive navigation bar
* Mobile hamburger menu
* Smooth scrolling navigation
* Modern hero section
* Interactive productivity dashboard
* Feature cards with hover animations
* Call-to-action sections
* Responsive design for desktop, tablet, and mobile
* Button hover effects
* Basic JavaScript interactions
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* Google Fonts

## 🎨 Design

The design uses a soft, minimal aesthetic with earthy tones, clean typography, rounded cards, subtle shadows, and smooth animations.

The interface was designed to feel calm and focused while maintaining a professional SaaS-style appearance.

## 📱 Responsive Design

The website adapts to different screen sizes:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

The navigation also changes into a mobile menu on smaller screens.
